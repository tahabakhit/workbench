# 10 Five-scenario trial of write-spec

Status: open
Blocked by: 09

## What

One light run of `write-spec` per kind of work, each in a throwaway folder
under `~/dev/ref/`: greenfield code, a brownfield repo, analytics (SQL or
dbt), a homelab change, a non-code decision document. For each, a fresh
session gets only "start issue 01" and the folder. Fix the skill between
runs when a run fails; rerun the failed scenario.

## Done when

`.scratch/workbench/trials/write-spec.md` lists all five scenarios, each
with its folder path and the fresh session's first reply showing it started
issue 01 without asking a question.
